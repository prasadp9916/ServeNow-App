# ServeNow CDD Context Repository

**Repo:** `servenow-app`

The authoritative specification and knowledge base for the entire ServeNow platform. All agents, developers, and automated systems derive their understanding of the domain from this repository.

## Purpose

- **Role:** Authoritative Specification
- **Format:** Markdown — CDD Knowledge Artifacts
- **Tracking:** Analysis & Work Tracking, Documentation

## Contents

- `.cdd/` — CDD configuration, agent guidance, artifact templates, context registry
- `universal-artifacts/` — Shared artifacts across all repos (enrolments, shared contracts)
- `features/` — Feature specifications and acceptance criteria
- `api-contracts/` — API contract definitions (v1)
- `information-working-analysis/` — Analysis, feedback, meeting notes
- `execution-roadmap/` — Delivery roadmap and sprint plans
- `api-reference/` — Full REST API documentation
